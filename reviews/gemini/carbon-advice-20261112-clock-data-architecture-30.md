# 时钟-数据协同审计与通用架构跃迁报告

【实测】现役自研基线：TMDS 为 `119.034 MHz`（hold `+0.048 ns`），固定数据统一移相模型界 `136.710 MHz` 伴 `29` 处 hold 违例（仅作数学参照，非芯片真实频率），`full_clock_search_002` 搜索 `512` 步仅接受 `1` 步（`slice$1646` 切至 `SPCLK33`，预测 setup `+0.267 ns` 至 `-2.146 ns`、hold `+0.048 ns`，尚无 native STA）；VexRiscv 为 `90.380 MHz`；TMDS 保留 `52` 个 ALU（`54.163 MHz`）与纯 `LUT4`（`74.901 MHz`）均败于 hold，跨边界预算宽映射 `210 s` 路由超时。

## 1. 双角时钟 Delta 模型实质缺口与必要否定实验

- **硬核、IO 寄存器与反相沿盲区**【实测】：`ClockDataModel` 仅放行四类 DFF 与 `IBUF`，遇 `SDPB`、`MULTALU27X18`、`IOLOGIC` 或反相时钟即报错；`FullClockSearchModel` 进一步拒收 `DFFCE/PE`，且未平移 `recovery/removal` 门限，无法覆盖 VexRiscv 硬核与异步复位路径。
- **单索引切片与脉宽失真**【实测+推断】：`measured()` 硬编码取 `([1][2],[2][0])` 同幅平移升降沿，但实测节点为 `3×4` 矩阵（`SPCLK33` 快角组内极差 `37~160 ps`），且 `probe.tr` 实测 `SPCLK33` 因高低沿偏斜将高脉宽由 `2.307 ns` 压至 `1.786 ns`（缩水 `0.521 ns`）。模型无 `min_pulse_width` 门禁，跨分支收发时原生 STA 的同角极值与 CRPR 机制亦未标定【不确定性】。
- **干线负载外推与搜索近视**【实测】：分支合并已现 `2.25 ps` 干线漂移，模型却假定根 `IBUF` 延时恒定并用 `1e9` 魔数滤弧；`priorities()` 静态固化配 `1 ps` 截断 `WNS` 字典序，丢弃所有未改第 1 瓶颈的单点移动，主别名预锁还排除了 `36` 条合法次级跨度路径。
- **必要否定实验**【建议】：① 导出 `full_clock_search_002` 跑全 IO 四类 native STA、脉宽检查与 `ownpr_sta_invariants`（`1.1 ps` 门限）；② 构造跨 `PCLKT1/SPCLK33` 的 FF 对与异步复位负控，核验同角索引与 CRPR；③ 注入 `base_configuration` 位冲突与未编码边负控，验证签核前阻断。

## 2. 非均匀 Useful Skew + Hold 修复评估与全设计上界

- **价值判断**【实测+推断】：仅宜作末级收尾（预计净增 `3%~8%`），**不值得作主攻方向**。TMDS 前 16 条关键路径为 `PI→FF`（`10.247 ns`），第 17 条即为 `FF→PO`（`SPCLK33` 发端达 `2.735 ns`，余量 `-0.227 ns`），外部端口锚定 `0 ns` 形成双向夹逼；合法校准时钟树慢角仅跨 `1.18~2.12 ns`，有向环净偏斜恒为零（制约 VexRiscv），且插 `LUT1` 修 hold 在慢角会反噬约 `2.1` 倍建立时间并增加拥塞。
- **可实现上界与防追 Worst**【建议】：在完整双向 DAG 上解**离散时钟菜单 MILP（及 LP 松弛界）**：以各汇点实测合法路径二元变量（受树父边一致与配置位约束）耦合双角到达、四类时序与脉宽下界，对可修端引入有界补偿 $h_p\ge 0$ 并同步计入慢角惩罚 $\alpha h_p$，最小化周期 $T$（`<1 s` 可解，仅作物理可行筛除界，不作频率声称）。搜索改用近临界带 `Log-Sum-Exp + λ·TNS`、每步动态重算关键度，并按 `GT10/GBO` 区域分支成组切换。

## 3. 架构对比与四条互异可落地路径

【实测+推断】TMDS 关键路径布线占 `64.3%`（`6.587 ns`），含 `22~44` 高扇出网及 `20+` 处因打包受限插入的 `LUT1` 透传（每级耗 `0.6~0.8 ns`）。单纯 `choice-DAG` 易因宽宏引脚聚集重演 `210 s` 超时；单靠 `carry-save` 不解控制/访存锥；曼哈顿全局布局曾退化至 `84.842 MHz`。建议推进四条正交通用路径（无项目专用 RTL 补丁，亦不引用他架构收益作频率承诺）：

1. **拥塞/扇出耦合异构 Choice-DAG（逻辑映射层）**【建议】：同图竞争长链 `ALU`（精确计入 `0.54 ns` 进链、`0.25 ns` 出链与 FF 适配税）、`LUT4..7` 余子式与浅 `LUT4`，切选叠加 CFU 引脚密度惩罚、扇出 `>8` 按象限复制及快角下界。*前提*：既有 `ALU/LUT` 标定与双向模型；*成本*：`~250` 行/`<15 s`；*失败判据*：路由 `>150 s`、hold `<+0.02 ns` 或四设计最小比值不升。
2. **预展平字级压缩树与前缀重构（数据通路层）**【建议】：在 Yosys 字级 `$add/$sub/$lt` 图上将串联窄加减/计数锥（$\le 8$ 位）经 `3:2/4:2` 进位保留树压缩后终加，宽算术（$\ge 12$ 位）保留单链 `ALU` 或双段进位选择。*前提*：字级网表与源码级 SAT/SMT 等价证明；*成本*：`~200` 行+`<30 s` 证明；*失败判据*：命中关键锥 `<2` 个、LUT 增 `>25%` 或等价失败。
3. **同 CLS 双 FF 混装标定与 DI 直连（器件打包层）**【建议】：突破多 FF 仅限 `0/2/4` 槽及扩展槽清空整块 CFU 的限制，差分标定 `(0,1)..(6,7)` 成对 FF 混装与 `DI` 直连路由，消除 `20+` 处 `LUT1` 透传并收缩版图跨度。*前提*：约 `600` 组原生属性/PIP 差分采样与负控；*成本*：`20 min` 标定+`180` 行；*失败判据*：配置位失配或局部拥塞恶化。
4. **跳数表+拥塞解析布局与时钟联合分配（物理实现层）**【建议】：用原生 RRG 离散跳数延迟表与开关盒历史拥塞替代曼哈顿代价，将 `PI→FF` 拉近固定 IO 环、逻辑贴紧 `SDPB/MULTALU` 列，合法化时同步分配 `PCLKT1/SPCLK33` 分支并做走廊增量重布。*前提*：跳数矩阵、瓦片容量与区域时钟表；*成本*：`~300` 行/四设计 `3~8 min`；*失败判据*：线延相关度 $R^2<0.85$、路由 `>180 s` 或低于现役基线。

## 4. 四设计通用性与最小比例目标（<1h）实验编排

- **短板与不确定性**【实测+不确定性】：公平官方基线、VexRiscv 未使用 `ERR` 焊盘（`282 vs 284`）及 `SDPB/DSP` 无界证明尚未冻结；按 `trial_003` 候选测算，TMDS 仅 `0.872x`（`1.20x` 需 `163.7 MHz`），而 int2float 自研 hold 仅 `+0.002 ns`，是最脆弱哨兵。
- **分轮执行（单轮硬限 `3000 s` 执行 + `600 s` 审计，`<40 GB`）**【建议】：先设**独立冻结轮**补齐 Vex 焊盘电气与存储校验，按统一预声明扫描锁定四设计官方 $F_{\text{base},d}$ 及 `1.224x` 评估频率。再按**路径 3+1 → 路径 4 → 时钟微调**推进组合轮：① `0~5 min`：`workspace_budget.py` 预留配额，跑完 `full_clock_search_002` 原生 STA 验真与 MILP 摸底；② `5~20 min`：单一无分支流程并行跑四设计综合、打包、CEC 与双向模型快筛，任一设计预测 hold `<+0.025 ns` 或 $\min_d R_d$ 退化即早停；③ `20~45 min`：限死单设计路由超时（小设计 `150 s`、Vex `420 s`），完成自研 P&R 与全 IO 四类 native STA、脉宽校验；④ `45~50 min`：仅当四设计全过等价/物理/hold≥0 门禁且 $\min_d(F_{\text{own},d}/F_{\text{base},d})$ 严格提升、已达标项不跌破 `1.20x` 时晋升，淘汰产物留哈希收据后无损归档。
