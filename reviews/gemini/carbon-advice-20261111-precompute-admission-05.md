# VexRiscv 跨寄存器有界预计算准入与闭环实验审查

6复制+29移位试验退化至 63.196 MHz（WNS -6.733 ns），证实移动高扇出父 FF 与后级 LUT 会触发潜藏路径及 `/CE` 线延全面恶化；集中证明器区分 `ASYNC_REG/dont_touch` 禁改与 `keep` 网保名观测（不误禁状态扩展）边界清晰。对前级有界函数 $C=F(Q)$ 预计算审查如下：

## 1. 预计算前沿选择：源端到达时间与反馈 SCC 拒绝判据

仅按 `<=6` 状态、`<=18` 变量与级数筛选忽视了合成次态锥 $F(T(Q))$ 对源引脚时序的透支。高收益前沿须跨“上游充裕控制/译码级 $\to$ 下游关键数据级”单向割集，执行三项硬拒绝：

- **源 D/CE/SR 到达时间与负载拒绝**：对任一非常量源输入 $p\in\bigcup_{s_i\in S(r)}\{D_i,CE_i,SR_i\}$，基线完整 IO STA 裕量须满足 $S_{\text{base}}(p)-\Delta_{\text{LUT}}(d_p)-\Delta_{\text{wire}}(p\to D_{\text{new}})-\Delta_{\text{load}}(p)\ge W_{\text{base}}+\epsilon$（$W_{\text{base}}=-2.425\text{ ns}$，取 $\epsilon\ge 0.5\text{ ns}$）。`ng_coopt_1455` 含全局最差捕获端 `slice$47880/D`（`-2.425 ns`），必将违例继续加长，直接拒绝；`ng_coopt_1445` 源 `slice$47807/D` 已达 `-1.193 ns` 且共接高扇出 `ce=1459`，`ownpr_output_state_cache.build` 自底向上 `lift` 将其置于 6-LUT 树叶端，串入 2~3 级 LUT 与线延后新 `/D` 易跌破 `-2.2 ns`，除非经到达时间感知辅因子分解将晚到信号推至末级 LUT4 后仍达标，否则拒绝。
- **零周期自反馈与紧耦合负裕量 SCC 拒绝**：若根 $r$ 组合可达自身源前沿任一 $D_i/CE_i/SR_i$，重接后形成 $Q_{\text{new}}\to G_p\to\text{LUT}_{F(T)}\to D_{\text{new}}$ 新自环，用往往更深的次态锥取代原前锥；若 $S(r)$ 与受控终点同属负裕量寄存器强连通分量（SCC），保原态单步前推无法降低环路平均延迟 $\max_C D(C)/|C|$，仅在环内搬移违例并拉扯新 FF 布局，均予拒绝。
- **旁路壁垒掩蔽拒绝**：受控终点剔除经 $r$ 路径后的次关键旁路裕量若仍接近原 WNS 且无法同步切齐，单点预计算收益被掩蔽，拒绝。

## 2. 核心 DFFSE（INIT=1）扩展与合法绑定检查

`ownpr_ff_configuration.py` 已校准核心 `DFFSE` 默认 `INIT='1'` 全部属性（`attributes[2]=15`、`13+(slot&1)=16`）。应在保持 `ownpr_output_state_cache.py` 末端 IO 缓存默认 `INIT=0`（隔离未校准 IOFF）不变的前提下，解耦开放内部核心 `DFFSE` 通道并执行四项检查：

1. **初态与复位域证明**：核验 $F(Q_{\text{init}})=1$ 匹配新 `DFFSE(INIT='1')`、`netnames` 无冲突 `'0'` 初值，且新旧 FF 共用受约束主时钟与同步 GSR 域，`synchronous_fanout` 阻断 `CLK/GSR/ASYNC_REG` 跨时钟域汇点。
2. **归纳步与控制优先级**：新 `DFFSE` 绑定常量 `SET=GND('0')`、`CE=VCC('1')`，转移退化为无条件采样 `D`，可直接复用 $2^{|V|}$ 穷举步证明；若源前沿后续纳入存量 `DFFSE`，源转移须按同步 `SET` 优先于 `CE` 置 `1` 求值。
3. **内部反馈折叠 CEC**：隔离 OBUF 证明不含回环，须将 `new_Q` 折回原网运行 `native_boundary_cec.prove`，联合验证全部状态输入、`next_bit` 观测口、`keep` 网及 `ALU`（`SUM/COUT`）组合输出等价。
4. **物理配置与消费端合法绑定**：`verify_materialized` 与 `compile_initial` 校验核心槽位 `(0,2,4)` 及配对 LUT 直连 `D == LUT.F`；重接仅限 `LUT1..4` 与普通路由可达的非级联锁定 `ALU` 数据脚（`I0/I1/I3`），严禁重接专用进位 `CIN` 与 `MUX2_LUT5..8` 私有级联输入 `I0/I1`。

## 3. 算术预计算纠偏与相对完整重定时/e-graph 的根本局限

- **纠偏**：上轮“算术路径不能做有界预计算”属过度概括。完整宽位算术的高位进位链输出（受 `>6` 状态及 `CIN->COUT` 级联支配，占本次被拒根主体）确超有界范围；但送入 `ALU` 的**每位前级状态函数**（操作数选择、取反控制或局部前锥，如 6 状态 13 变量的 `ng_coopt_1445/1455`）完全具备有界预计算的数学可证性。
- **根本局限（严格保接口周期且保留原状态）**：① **支撑宽度与硬核墙**：反向提升随 $|V|$ 指数膨胀且受阻于 RAM/DSP/宽进位链，而完整重定时按割边放 FF、无关上游状态宽度且可删原冗余 FF；② **单步视界与代数深度不变**：保原态仅属单步复制前推，源 `D/CE` 紧迫或处反馈 SCC 时无法多级均摊裕量，亦不能如 e-graph 重映射那样在周期内做结合律/辅因子重组以压减级数并将晚到信号推至末级引脚；③ **纯增量负载与专用线壁垒**：不删原逻辑使新增 6~7 个 LUT 叠加源 `D/CE` 电容与局部拥塞，且无法切入 `ALU.CIN` 等专用级联线内部。

## 4. 下一步唯一闭环实验建议（预算 <= 3500s）

- **实验设计**：执行**零原单元移位、到达时间与 SCC 门控的单候选内部预计算闭环试验**。打通核心 `DFFSE(INIT='1')`、合法 `ALU(I0/I1/I3)` 重接与折叠反馈 CEC（IO 缓存仍限 `INIT=0`），对 `8+7=15` 个有界根运行静态 SCC 与基线 STA 门控：淘汰 `ng_coopt_1455` 及任何含零周期自环或 $\min_{p}[S_{\text{base}}(p)-\Delta_{\text{lift}}(p)] < -1.2\text{ ns}$ 的候选（实测 `1445` 是否被 `47807/D=-1.193 ns` 拦截），仅取**净裕量排名第 1 的幸存根**（如覆盖 `-2.361 ns` 7 终点的 4 状态/8 变量根 `ng_multicut_ng_coopt_1541_leaf_3` 或最优 `INIT=1` 根），100% 锁定存量单元坐标，增量放置新 FF 与合成 LUT，完成证明、自研布线、导出与 110 MHz 完整 IO STA（`<=3500s`）。
- **观察与推测**：记录 15 根门控表、新 FF `/D` 裕量、源 `D/CE` 负载增量、受控终点增益及全局 Fmax/WNS/TNS/Hold。推测锁死原坐标可杜绝 `-6.733 ns` 潜藏恶化，门控可防止新 `/D` 越界，受控路径局部改善 `0.5~1.2 ns`，并直接检验全局 WNS 是否受并行 ALU 壁垒掩蔽。
- **失败判据**：总耗时 `>3500s`；折叠 CEC、`keep` 安全或 `compile_initial` 任一失败；新 `/D` 或源 `D/CE` 跌至 `<=-2.425 ns`；`hold < 0 ns`；或完整 IO STA 未超越基线（`Fmax <= 86.833 MHz` / `WNS <= -2.425 ns`）——数学等价绝不等同时序提升，无净 STA 增益即回退。
