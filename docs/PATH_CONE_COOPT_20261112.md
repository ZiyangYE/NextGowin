# 物理路径锥协同优化与 89.2 MHz 验收

本轮实现了普通 LUT 路径锥复制、接收端附近布局、快速输入引脚置换与时序驱动增量布线的共同候选评价。VexRiscv 最高完整复核频率由 **88.6 MHz 提高到 89.2 MHz**，setup **+0.009 ns**、hold **+0.133 ns**，违例均为零。原厂仅用于最终 STA、配置编码及已标定器件数据，没有运行原厂布局或布线。

**110 MHz 目标未完成，整个 GW5AST-138 通用工具链也未整体验收完成。** 本轮没有达到全局 WNS 改善 0.5 ns 的架构里程碑，不能把一个地址端点的较大改善当作整机提升。

原厂 reported Fmax 为 **89.273 MHz**；89.2 MHz 是另一次进程中对同一物理配置进行完整 STA/编码复核后的合格值。频率复核只改变主时钟周期，保持全部 I/O 时序命令、50 ps hold uncertainty、固定引脚、电气属性及接口周期。

原始搜索、四次有界搜索的选择依据、候选失败/超时记录、原厂报告、独立模型验证与检查点均保留。搜索按事先设定的 2100 秒截止停止；完整验收及三项 raw 回归审计在约 **2580 秒**完成，后续文档整理仍受同一 3450 秒硬预算约束，没有为重试重置原截止时间。前三次主要搜索分别测得 36、35、24 个候选，最后一次收尾测得 2 个候选，另有 3 个有界候选布线超时；超时和退化候选均未被采用。

## 8.8 ns 究竟在哪里

此前提到的约 **8.835 ns 是整条地址路径上多段布线的总和，不是一根网络的延迟**。原路径从区域寄存器 `(70,92)` 经普通 LUT 和固定宽 MUX `(71,87)`，向东绕到 `(73,105)`、`(77,114)`、`(70,113)`，最后折返 BRAM `(63,94)`。中间 LUT 有共享扇出，直接搬走整锥会拖慢其它连接；只按几何距离选址也不能预测整树负载回弹。

新方案保留共享逻辑给原有接收端，复制所需上游逻辑并将指定末级 LUT 移近接收区域。末级 LUT 保留原输出 bit，所以硬核引脚、寄存器和其它固定边界的逻辑连接不变。每次仍重新路由和实测所有改变网络的完整接收树。

`ng_memory_0.1.0/ADB[7]` 的模型裕量从 **-2.169 ns 改善到 -0.521 ns**，约改善 **1.648 ns**；该端点最差路径的起点也发生变化。新最差见证路径布线合计约 **6.676 ns**，单元合计约 **2.644 ns**，不能将其与旧路径分解当成同一起点、同一路径的逐项差值。独立原厂对全部 2798 个 setup 和 2798 个 hold 端点核对，最大 slack 误差约为 **0.000622 / 0.000500 ns**。

全局瓶颈转移到另一条 FF 数据路径：布线约 **8.157 ns**，单元约 **2.682 ns**；另外 `ADB[5]` 仍有约 **-2.046 ns** 的模型裕量。这解释了为什么单端点改善 1.65 ns，整体仅增加 0.6 MHz。

## 新增算法及边界

- 从全图时序的临界端点回溯极性相关路径，提取普通 LUT 片段，包括单级 LUT、共享前缀和配对 FF 的固定末级 LUT。
- 保留共享上游原件，克隆所需函数；根输出 bit 不变。已配对 FF 的根 LUT 保持原位，时钟、FF、硬核和宽 MUX 宏保持不动。
- 先寻找合法空位，再按时序与连接关系排名。BRAM 附近三格范围实际没有空闲 LUT 槽，因此搜索半径按 3、5、8、12 格扩展；不移动已有固定引脚。
- 将晚到输入置于当前标定条件下较快的 LUT4 引脚，精确重算 INIT。补齐输入使用现有物理 GND，真值表不依赖这些填充脚。
- 依据每个物理接收端的全图裕量设置路由权重。权重只进入路由求解，不改动导出的物理连接元数据。
- 支持从精确绑定的旧搜索继续：重新测量改变的树，重新检查原始 hold 下界，最终对原始网表到整个最终网表重新证明等价。
- 尝试组合已测候选后，重新联合布线和评价整个批次。单个候选有效不代表批次有效；本轮的六锥批次发生 WNS 回弹，已拒绝。

当前复制集合主要来自路径片段，尚不是完整的多输出 DAG 闭包。批次为避免冲突禁止成员相交，会限制不同 BRAM 地址根共享一个新前缀副本。这是下一项结构改进的候选，尚未实现或验证。旧副本仍保留，也尚未实现通用的零负载逻辑清除。

本轮新增快引脚和联合复制，并不构成任意算术模式、任意硬核模式、动态时钟移动或任意 I/O 电气配置的支持证明。既有 ALU、宽 MUX、14 个硬核的模式与物理位置保持在已标定范围。

## 验证与泛化回归

最终设计通过全网表固定状态组合等价检查，包含 **1858 个边界实例、8716 个观察点**；独立物理审计检查 **6595 条普通网、50348 个 PIP、1325 个时钟汇点和 363 条进位链接**。284 个 I/O 端口及电气约束保持。原厂完成 STA、配置读回/投影检查和位流生成，未自动烧录硬件；不声称完成开发板验证。

UART、int2float、TMDS 使用与主工程相同版本的操作器，分别实际测量 3、4、4 个候选。三者均选择不改变原实现，原厂 STA 通过频率仍为 **197 / 167.5 / 112.3 MHz**，同时保住 95% 回归线；复用的 STA 与原始物理实现按精确 SHA 绑定。这是 raw 搜索后的不变输出，未在失败后替换成保底结果，也不证明其它设计获得了提速。UART 另有一次没有物理变化的提案被记录为跳过错误。

第一次泛化审计因 int2float 的历史检查点缺少 `qualified_mhz` 字段而未完成，原记录保留；第二次从冻结评估策略取得该字段并重新核验，三项通过。不是忽略一次实际时序失败。

28 项针对性测试通过，覆盖菱形重汇聚与共享负载下的复制等价、端口 bit 分配、配对 FF 约束、全部输入置换与填充真值、接收端权重、进位准入、完整时序图重建和路径见证重建。

## 研究依据与实际采用范围

[FPL 2025 的作者大学记录](https://biblio.ugent.be/publication/01KMQW5B5CPZEDJMGYKMX4F8E6)介绍以受控节点复制、重构改善互连局部性的思路，并将论文结果标为初步结果。本项目参考这一方向，未宣称复现其完整算法或数值。[TD-Placer 作者预印本](https://arxiv.org/abs/2512.00038)支持关注全网交互和细粒度时序权重；本轮使用原生整树实测与逐接收端权重，没有实现其非线性全局布局器。另核实了 [ICCAD 2025 可微时序驱动 FPGA 布局论文的作者发表记录](https://www.cerc.utexas.edu/utda/publications/publications.html)，未取得完整正文，不据二手摘要声称复现。

Gemini 的有效评审为根目录 `carbon-advice-20261112-bram-cone-13.md`，并另有 `carbon-advice-20261112-multiroot-next-14.md` 讨论下一轮多输出共享 DAG。第二份报告写于本轮终审结果交接前，其中 88.6 MHz 是它收到的旧合格值，当前以本文件和完成审计中的 89.2 MHz 为准。两次未生成报告的咨询调用未作为结论来源。采纳建议前均结合本地实现、真值测试和物理测量核查；其潜在收益估计不是本项目测量结果。尤其不采纳把两轮局部搜索收益小当成固定状态边界已达理论极限的说法。

## 复现入口

最高结果的四工程检查点为：

`results/vexriscv_bram_cone_trial_001/all_designs_qualified_checkpoint.json`

在项目根目录，使用一个不存在的新输出目录，可对冻结物理实现重新执行完整导出/验收：

```powershell
runtime_bundle/python/python.exe scripts/replay_coopt_checkpoint.py --case vexriscv --report results/vexriscv_bram_cone_trial_001/all_designs_qualified_checkpoint.json --target-mhz 89.2 --seconds 420 --out results/vexriscv_path_cone_replay_NEW
```

这会先校验所有来源哈希，再用本项目的配置合成与原厂最终 STA/编码复验既有自研布局布线结果。输出前必须满足工作目录容量预留；当前机器的原厂运行时和项目内器件标定数据仍是依赖。

算法入口为 `scripts/ownpr_joint_lut_search.py --operator cone`，核心变换见 `scripts/ownpr_path_cone.py`。本轮早期搜索曾修订选址窗口和候选策略，各搜索目录的 `sources/` 保存实际执行版本，不能把当前策略重新运行的结果冒充旧版本逐位复现。已有最终候选可直接复验；新的有界搜索可能选择不同路线。

关键证据位于 `results/vexriscv_bram_cone_trial_001`：`candidate_selection.json`、`export/manifest.json`、`native_model_validation.json`、`qualification/manifest.json`、`qualified_replay_checkpoint.json`、`completion_audit.json`。泛化审计见 `results/path_cone_structural_guards_001/native_guard_audit_002.json`。

大文件采用无损压缩，并按解压后的原始字节核对 SHA。既有交接 ZIP 未改动。总目录继续受 40,000,000,000 字节上限约束。

## 下一轮应解决什么

首先检验多输出路径锥共享：多个接收根复用一个新前缀副本，减少重复输入负载与地址入口拥塞。需要同时覆盖竞争的 FF/宽 MUX 前后锥，不能只修 BRAM 一类路径。若实测仍显示固定 FF/宽宏边界阻止有价值的迁移，再先补齐移动状态与时钟树的原生双角校准及证明机制。

继续以全图 WNS/TNS、逐端点 hold、完整 I/O STA 和一小时完整尝试为门槛。不能从“尚未出现大幅收益”推出已达到器件极限，也不能承诺上述方向必定达到 110 MHz。
