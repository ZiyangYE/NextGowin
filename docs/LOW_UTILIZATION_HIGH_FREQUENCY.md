# 低占用、高频综合：诊断与新的验收目标

更新：2026-11-02。目标是各主要资源约低于 40%，在 150 MHz 以上获得多数设计的显著时序收益。以下区分实测证据与建议；尚未证明达到该目标。

## 当前几何均值的正确解释

新配方开发集十个完成项的 Fmax 比值几何均值为 0.837054；原厂未布通的 log2 单独保留。该数值描述原测试封装下的整体时序，不能直接解释为内部综合逻辑普遍慢 16.3%。

重新检查原始报告发现：自主结果十项中，八项的首条最差报告路径是 FF→输出缓冲；仅 sin、multiplier 为内部逻辑路径。测试将输入/输出寄存器放在核心区域，禁止 I/O 寄存器打包，I/O 延迟设为 0，且未提供固定引脚 CST。整体 Fmax 混入了时钟插入、输出缓冲及引脚布线的影响。

例如 ctrl 的自主最差路径没有经过待优化组合逻辑：时钟插入约 4.075 ns，C2Q 0.331 ns，输出布线 2.070 ns，OBUF 2.528 ns，合计约 9.003 ns，对应 111.070 MHz。原厂相应最差输出路径为约 7.548 ns，对应 132.488 MHz，其输出布线为 0.645 ns。两者时钟入口同为 IOR85[A]，但最差输出端位置不同。不能把这个差值全归因于 LUT 技术映射。

现有报告只列部分路径，不能据此反推出被 I/O 路径遮住的真正内部 Fmax。真实板级约束继续有效；建立核心性能评测是新增口径，不是删除 I/O 违例后宣称整板收敛。FPGAFly 有原始 CST 和五个时钟的独立审计，其 77.100 对 74.565 MHz 的单次板级对照仍保留。

## 低占用并没有自动解决问题

十个完成项的自主 LUT 最大为 12892/138240，约 9.33%；FF 最大约 0.222%，LW 全为 0/8。它们本来就是低内部资源占用设计。部分设计却使用 44%–93% 的 I/O；若也要求 I/O <40%，留下 ctrl、int2float、cavlc、router、sin 五项，几何均值仍为 0.898351。

| 设计 | 原厂 / 自主 LUT | 原厂 / 自主 Fmax，MHz | 关键证据 |
| --- | ---: | ---: | --- |
| ctrl | 51 / 58 | 132.488 / 111.070 | 自主首条最差路径为 FF→OBUF |
| router | 47 / 141 | 129.265 / 116.225 | LUT 增至 3 倍；最差报告路径仍由输出边界主导 |
| sin | 2172 / 4847 | 26.499 / 24.867 | 内部最差路径单元含 C2Q 延迟 15.600→10.565 ns，布线 21.751→29.560 ns |
| multiplier | 8621 / 12892 | 21.830 / 13.970 | 内部最差路径单元含 C2Q 延迟 15.782→14.800 ns，布线 29.737→56.775 ns |

表中路径分量是两侧各自最差报告路径，未声称是同一逻辑路径。面积膨胀和布线恶化同时存在；精确因果需用固定引脚及消融实验验证。低全局占用不保证局部布线短、簇紧凑或硬核位置合适。

当前 mapper 的主要缺口是：固定线代价、粗粒度 LUT 代价、零到达时间下的全局最小延迟目标、缺少完整 SDC 到端点预算的传播，以及没有经过验证的布局/拥塞反馈。固定宽 cut 和复制配方又被推广到不同规模设计。原厂较好的逻辑压缩、共享结构和物理排序没有被充分复现。

FPGAFly 的 BRAM 268/340 约 79%、DSP 约 46%、LW 6/8 为 75%，不属于本轮低占用目标集。针对它构造的控制路径惩罚 206 ps 不能当成低占用设计的通用最优值。

## 建议的实现顺序

用户后续明确规定：**验收必须包含 I/O，且禁止重新分配引脚。** 以下涉及内部核心评测的建议仅用于瓶颈诊断，不能代替验收。最新固定引脚、完整 I/O 结果见 [实际工程执行记录](PRACTICAL_138K_OPTIMIZATION.md)。

后续执行进展：已经完成固定引脚、输出 IOB、160 MHz 及紧凑映射对照，并接入公开流程；详见 [布线延迟实测结果](ROUTING_DELAY_FINDINGS.md)。新核心高频评测与局部物理反馈重映射仍是开发项。

1. **先建立可解释的高频评测。** 核心模式明确报告 launch FF→capture FF 的有效 setup/hold；通过同一保留边界的测试封装减少外部引脚对核心指标的限制。板级模式继续完整报告真实 I/O 约束，固定相同 CST、I/O 电气设置及 IOB 打包策略。禁止把核心频率当成整板频率。
2. **按 160/200/250 MHz 冻结目标。** 周期分别为 6.25/5/4 ns；将时钟、C2Q、setup、例外与边界要求传给映射目标。不能仅把最终 P&R 的周期改小而沿用不感知端点预算的综合选择。
3. **保留紧凑实现并建立小设计候选组合。** 固定比较 LUT4、宽 cut、面积恢复、EqMap 适配等少量候选；复制与控制改写分别有关闭版本。按原生时序验证选择，整个自主尝试共享一小时预算。原厂只作对照，不作为自主候选的种子或冒充自主输出的兜底。
4. **优先修复关键窗口。** 对少量临界锥做有时间上限的精确 LUT4/私有 MUX 综合和多输出联合优化，同时计算共享逻辑、实际活跃面积及端点延迟。保留 Pareto 候选，避免只追求抽象逻辑层数。
5. **引入物理反馈。** 先使用已经验证可读的 P&R 路径、扇出和位置证据，再评估布局阶段接口。复制仅针对临界路径，协同检查全部同等关键路径、上游负载和 LW；改善不成立就回退。全局有空余资源不作为放大复制范围的理由。
6. **按结构识别算术与存储。** 在位级化之前保留字宽、符号、算术 DAG、存储端口与碰撞语义，联合选择 ALU/DSP/BRAM。时序允许时吸收已有寄存器；移动状态必须验证时钟、使能、复位与初值。默认保持外部周期延迟，增加流水级属于另一个架构版本。

引脚模型应进入候选生成，但须验证逻辑引脚与实际物理弧的对应关系。已有后置引脚实验中 ctrl 没变，priority 仅从 88.771 提升到 90.944 MHz，不能预设仅靠换脚就达到 150 MHz。

## 建议的验收合同

- 在测试前固定资源资格，分别列出 LUT/ALU/FF、BRAM、DSP、LW，以及 I/O/时钟资源。以原厂结果确定入组资格；候选越过资源上限记为失败，不移出统计。
- 测试集覆盖控制、选择/互连、算术、DSP 流水和存储控制，建议至少 20–30 项，按 RTL 家族划分开发与保留验证集。不能只增加同一模板的参数实例来代表泛化。
- 将“原厂已能满足高频目标”“原厂接近目标”“原厂远低于目标的深组合电路”预先分组；第三组保留为挑战集，不承诺低占用就能达到 150 MHz。
- 建议将“显著”约定为：至少 70% 的合格设计有 ≥10% 的有效 Fmax 提升，总体几何均值 ≥1.10；回退超过 5% 的设计不超过 10%。这是建议目标，不是已取得结果。
- 有效结果要求原目标频率下 setup、hold、pulse、路由与资源均通过。另报最大可收敛频率的搜索结果，避免把带 hold 违例的报告 Fmax 当作可用工作频率。
- 固定工具、源文件、约束与候选预算；支持 seed 时做同 seed 配对，不支持时按固定设置重复并明确确定性边界。所有失败和回退保留。

## 论文依据和证据

[EqMap（ICCAD 2025）](https://www.csl.cornell.edu/~zhiruz/pdfs/eqmap-iccad2025.pdf)支持保留等价选择和面积改善，其结果不能直接等同 Gowin 布线后高频优势。[FAPO（2026 预印本）](https://arxiv.org/html/2610.06937v1)强调复制的上游负载、最终面积和同时关键路径条件。[PhyMap / PigMap3（ASP-DAC 2026）](https://www.aspdac.com/aspdac2026/archive/pdf/5F-4.pdf)提供物理反馈映射的依据，但其 ASIC 流程需要额外的 Gowin 适配。
