# 统一综合、布局、布线优化的可行性判断

用户将“一步完成 synthesis + Place + Route”作为建议提出，并明确要求自行判断可行性。当前决策：**采用统一状态与联合候选评价的方向；暂不全面重写，不追求全芯片精确单体求解，也不把一个脚本封装三阶段称为算法融合。** 目标仍是固定接口周期、固定引脚的 VexRiscv 110 MHz，UART/int2float/TMDS 作为守卫。

后续实测更新：已完成限定范围的双向 setup/hold 图、整树实测的等价源/子树联合事务，最高完整验收 88.1 MHz。保留此文初始判断，下述“尚未完成”以[后续实现、上界复核和下一阶段任务](ROUTED_SUBTREE_AND_ARCHITECTURAL_BOUND_20261111.md)为准；当前尚未完成一般组合改图及映射/打包/位置的共同搜索。

## 证据与距离

已验收 87.3 MHz，对应约 11.455 ns；110 MHz 对应 9.091 ns，需要减少约 2.364 ns，即周期缩短 20.6%。当前代表关键路径 cell 3.945 ns、wire 7.474 ns。若逻辑和时钟项不变，约需消除这条路径三成布线延迟；其他竞争路径也必须同时改善，不能将单条局部收益当作整机收益。

最近的联合复制与布局试验中，29 次移动每次均降低固定加权几何目标，总下降约 4,071 个加权距离单位，但报告 Fmax 从 86.833 降至 63.196 MHz。相同状态复制、固定原单元位置则完整验收 87.3 MHz。因此“把决策放到一起”有必要的应用场景，但**错误的共同目标仍会把联合优化引向更差结果**。此证据不足以证明全部阶段划分就是停滞原因，也不足以证明必须全面重构才能达到 110 MHz。

现有 103 扇出源仅剥离四个报告脚，99 个原接收支路仍在，隐藏宽宏分支接管关键时序；新副本 RESET 又出现 13.383 ns 布线。当前最应补的是全接收集合、共享树负载、竞争路径及 D/CE/RESET 的同时评价。

## 建议的最小架构改造

保留已有器件资源图、原语校准、cut 枚举、资源打包、合法化、归纳 CEC、增量路由和 DLL 整树测时。建立常驻的网表、布局与路由状态；一次候选可以同时选择等价映射、复制/共享、打包、位置与受影响路由。接受候选时检查全局时序结果，失败时将整个候选回滚。

需要补三项核心能力，当前尚未完成：

1. **可改图的全局时序评价**：复用已验证范围内的慢角 arrival 图，增加反向 required time、快角 hold 与改图更新；已有 D/CE/RESET 的最大到达传播不应重复建设。对新时钟位置、硬核模式和 I/O 条件逐项核查，不能将早期单时钟实现的误差数值外推到任意候选。
2. **完整接收树与状态输入的候选生成**：从全部逻辑接收端及已有等价状态组出发分配负载，而非只用报告中的最差路径脚。对共享 D、CE、RESET 的新增负载同步预算；重用已有副本时也必须证明归纳等价。
3. **联合候选事务层**：跟踪多单元变换、位置与端点变化所影响的全部网络。即使某个接收端没有移动，同网其他分支变化也可能改变其延迟，必须重新测完整负载树。联合候选以同一全局 WNS/TNS、hold、资源与拥塞检查接受/回滚，避免先采纳映射再设法挽救路由。

不需要现在引入全芯片 e-graph、精确 ILP、GPU 或新的前端来验证这个方向。它们是否值得取决于新瓶颈，而不是“统一”这个名称。分层求解、粗细两级物理表示和最后详细路由仍可存在。

## 下一次试点及证伪条件

先完成可校核的时序评价和事务接口，再在同一 3,500 秒预算内比较至多三类联合候选：完整扇出重分配；完整扇出加竞争算术前后锥重映射；再加入控制树与 BRAM 走廊的联合调整。候选须覆盖多条竞争路径，不再以一处 LUT 的几何收益决定采用。详细 STA、等价性和配置检查仍是最终门槛，完整最坏输出按实际规模预留，不能把 500 MB 当作所有阶段足够的固定预算。

试点目标是全局 110 MHz WNS 有明确改善，并同时检查算术、控制、硬核地址及新状态输入的裕量。至少约 0.5 ns 的全局改善、模型与最终 STA 在声明范围内偏差小于 0.05 ns，可作为继续扩大的工程门槛；这些数值是待验证标准，不是预期收益或达成承诺。若候选普遍只改善单个分支、模型无法解释潜藏退化或完整尝试超时，先修正相应能力，不能用“重写全部架构”代替诊断。

寄存器 SCC 和旧源 D 裕量可用于保守筛选，但状态增强能改变电路状态表示，SCC 成员关系本身不是不可能改善的数学证明；同样，未测得收益不能称为达到器件物理极限。

Gemini 的独立评估在根目录 `carbon-advice-20261111-unified-feasibility-06.md`。其建议经过本项目核查：当前硬核实际为 6 个 DPX9B、4 个 SDPX9B 与4个 MULTALU27X18；是否处于关键路径需以具体路径为证。固定布局不意味着未移动网络负载绝不退化；全接收重新分配、控制端和最终完整 STA 仍不可省略。
